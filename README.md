## 这是什么

写给混的人。

混的人不是废物，不是躺平，更不是摆烂。他明知世界不讲道理，还是把日子过出了韵律：失败的婚姻叫缘分尽了，没抢到的 offer 叫时机未至，迟到叫让世界等一等他。你可以说这是自我安慰。请注意，**能自我安慰，本身就是一种顶级生存能力。**

全书六卷四十一章。道、佛、八字、六爻、占星、塔罗，被毫无敬畏地浇在当代的地砖上。先贤写经的时候，写的也是他们那个时代的外卖、房租和烂桃花。只不过他们管外卖叫化缘，管房租叫挂单，管烂桃花叫劫。

读到某句让你沉默三秒，合上手机，去做你一直在逃避的那件事。本经的使命就完成了。

> 经曰：人生在世，不如意事十之八九。剩下那一二，也未必轮得到你。

## 在线阅读

GitHub Pages 已部署：**<https://fatasia.github.io/PrankHandbook/>**

零构建，纯静态。docsify 直接渲染 Markdown，改完推上去就是新版。

## 本地运行

```bash
git clone https://github.com/fatasia/PrankHandbook.git
cd PrankHandbook
python -m http.server 8080
# 打开 http://localhost:8080
```

任何静态服务器都行（`npx serve`、VS Code Live Server、nginx……）。不能双击 index.html 直接打开——docsify 需要通过 HTTP 加载 Markdown。

## 部署到你自己的 Pages

1. Fork 本仓库
2. 仓库 Settings → Pages → Source 选 `main` 分支，目录选 `/ (root)`
3. 一分钟后，`https://你的用户名.github.io/PrankHandbook/` 上线

`.nojekyll` 已内置，无需任何构建配置。
