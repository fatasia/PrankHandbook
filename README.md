## 这是什么

《混经》是一本开源的恶搞生活指南，六卷四十章，覆盖从做饭、健身、谈恋爱，到融资、脑机接口、玄学统一场论的一切人间事务。

- **道佛八字六爻占星塔罗**，全部毫无敬畏心地浇筑在当代生活的每一块地砖上：减重丹药谱、薅学兵法、健身房流派斗争、赛博干仗话术、白事习俗观察、玄学统一场论……
- **该正经的地方真正经**：看病与理赔、戒烟路线图、早泄的健康科普、GLP-1 药物盘点，全部基于真实医学与监管信息，搜得到出处。
- **该搞笑的地方绝不掉链子**：弱智吧式歪理 + 古今混搭（老庄红楼金瓶梅水浒、诺贝尔奖、卡尼曼），一句话反转，笑着笑着沉默三秒。

> 经曰：人生在世，不如意事十之八九。剩下那一二，也未必轮得到你。

## 在线阅读

GitHub Pages 已部署：**[https://fatasia.github.io/PrankHandbook/](https://fatasia.github.io/PrankHandbook/)**

零构建，纯静态。docsify 直接渲染 Markdown，改完推上去就是新版。

## 本地运行

```bash
git clone https://github.com/fatasia/PrankHandbook.git
cd PrankHandbook
python -m http.server 8080
# 打开 http://localhost:8080
```

任何静态服务器都行（`npx serve`、VS Code Live Server、nginx……）。不能双击 index.html 直接打开——docsify 需要通过 HTTP 加载 Markdown。

## 部署到你自己的 Pages

1. Fork 本仓库
2. 仓库 Settings → Pages → Source 选 `main` 分支，目录选 `/ (root)`
3. 一分钟后，`https://你的用户名.github.io/PrankHandbook/` 上线

`.nojekyll` 已内置，无需任何构建配置。
